# Dallian Luxe Hair

Dallian Luxe Hair is an e-commerce frontend built with Next.js, React, JavaScript, and Tailwind CSS.

## Tech Stack

- Next.js 16
- React 19
- JavaScript / JSX
- Next.js App Router
- Tailwind CSS 3.4.17
- ESLint
- Lucide React
- Framer Motion
- Recharts
- Emotion
